# Tournée Générale

Carte interactive des lieux pour jouer aux jeux de bistrot autour de toi (billard, fléchettes, baby-foot, pétanque, karaoké, quiz…), avec ta position en temps réel et des filtres par jeu.

Site : https://paullmoreau.github.io/carto.paris/

Données © OpenStreetMap (Overpass API).
